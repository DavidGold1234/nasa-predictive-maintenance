# NASA Predictive Maintenance

Este proyecto desarrolla un sistema de análisis y modelado para mantenimiento predictivo
utilizando el dataset NASA CMAPSS, como parte de un trabajo de tesis.

## Objetivo
Analizar datos de sensores de motores aeronáuticos y construir modelos predictivos
para estimar la vida útil remanente (RUL).

## Estructura del proyecto
- `data/`: datos crudos y procesados
- `notebooks/`: análisis exploratorio (EDA)
- `src/`: código fuente del pipeline
- `requirements-eda.txt`: dependencias para análisis
- `Dockerfile`: entorno reproducible del pipeline

## Tecnologías
- Python
- Pandas, NumPy, Scikit-learn
- Jupyter
- Docker
